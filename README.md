# Accessible News Hub
A responsive frontend news portal built for a Week 3 accessibility and user-experience project.

## Technologies
HTML5, CSS3, Vanilla JavaScript and ARIA.

## Features
- Semantic page landmarks and skip-to-content link
- Responsive navigation with expanded/collapsed state
- Visible keyboard focus indicators
- Accessible article-summary dialog with Escape support and focus return
- High-contrast mode
- Labelled feedback form with live status message
- Reduced-motion support

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Accessibility review
Run Chrome Lighthouse (DevTools → Lighthouse) and/or the WAVE browser extension. Record the actual results from your own test; this project does not claim an unverified score.
